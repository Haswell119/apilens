JSON to CSV converter — frequently asked questions

What JSON shape does this converter accept?

An array of objects, e.g. [{"a":1},{"a":2}]. The keys of the objects become CSV column headers. A single object is treated as a one-row array.

What happens to nested objects and arrays?

They are stringified as JSON (e.g. {"x":1}) and placed in the cell, so no data is lost. Use a JSONPath query to flatten a structure before converting if you need specific fields.

Is my data uploaded anywhere?

No. Conversion runs 100% in your browser — nothing is uploaded, logged or transmitted. APILens is MIT open source with no ads and no analytics.

How are special characters like commas and quotes handled?

Cells containing a comma, quote or newline are wrapped in double quotes and inner quotes are doubled (""), per the standard CSV (RFC 4180) escaping rules.

What if my objects have different keys?

The converter collects the union of all keys across all objects as the header row, and fills missing values with an empty cell — so no column is dropped.

Does it work with large files?

Yes for typical API payloads (up to ~20k nodes / 2 MB free). For larger exports, APILens Pro raises the limit to 200k nodes / 20 MB and funds the open-source project.
