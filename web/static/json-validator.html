JSON validator — frequently asked questions

How does this JSON validator find the error line and column?

It uses your browser's own JSON parser, which reports the character position of the first error. APILens converts that offset into a human-readable line:column location and shows the parser's message alongside it.

What are the most common JSON errors?

Trailing commas, missing commas between items, single quotes instead of double quotes, unquoted keys, and comments (// or /* */). JSON does not allow comments, so this validator flags them.

Is my JSON uploaded anywhere?

No. Validation runs 100% locally in your browser — nothing is uploaded, logged or transmitted. APILens is MIT open source with no ads and no analytics.

What counts as "valid" JSON?

JSON (RFC 8259) must be valid UTF-8 and be one of: an object { }, an array [ ], a string, a number, true, false, or null. Keys and strings use double quotes.

What's the difference between validation and formatting?

Validation checks correctness. Formatting (pretty-print or minify) rearranges whitespace. Use the JSON formatter to beautify valid JSON, and this validator when you suspect an error.

Does this work with large JSON files?

Yes — up to about 20k nodes (2 MB) in the free tier. For large files, the APILens Pro tier raises the limit to 200k nodes / 20 MB and includes JSONPath and JSON diff.
