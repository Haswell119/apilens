JSONPath — frequently asked questions

What is JSONPath?

JSONPath is a query language for extracting values from JSON documents — the JSON equivalent of XPath for XML. It's standardized in RFC 9535 (2024) after years as a de-facto standard.

Which JSONPath features are supported?

Dot notation ($.key), array indexing ([0], negative [-1]), wildcard ([*]), recursive descent (..), and filter expressions ([?(…)]) with comparisons, @.key access, and && / || logic.

How do I filter an array?

Use a filter expression: $.store.book[?(@.price < 10)].title returns the titles of books under 10. Chain with && / || — e.g. [?(@.price < 10 && @.inStock)].

Does my JSON leave my browser?

No. The evaluator runs 100% client-side. Nothing is uploaded, logged or tracked.

What's the difference between . and ..?

$.book.title reads a direct child. $..title is recursive descent — it finds every title key at any depth, which is handy when the structure is unknown.
