What Base64 does (and does not) do

Base64 turns arbitrary bytes into 64 printable ASCII characters so the data survives transport through text-only channels: JSON fields, HTTP headers, data URLs and email. It is encoding, not encryption — anyone can decode it. Size grows by about 33% (3 bytes become 4 characters), plus padding.

ModeAlphabetUse it for
StandardA–Z a–z 0–9 + / with = paddingJSON bodies, data URLs, email attachments
URL-safe- and _ instead of + and /JWT segments, query strings, filenames
Unpaddedno trailing =JWT segments and some URL parameters

A JSON Web Token is three URL-safe, unpadded Base64 segments joined by dots — if that is what you are looking at, the JWT decoder shows the header and payload as JSON directly.

Frequently asked questions

Is this Base64 tool private?

Yes. Encoding and decoding use the browser's own TextEncoder and atob/btoa. There is no network request of any kind, so API keys, tokens and credentials pasted here stay on your machine.

Does it handle accented characters and emoji?

Yes. Input is converted to UTF-8 bytes before encoding, so non-ASCII text round-trips correctly — unlike a naive btoa() call, which throws or mangles them.

Standard or URL-safe — which do I need?

Use standard Base64 for JSON bodies, data URLs and email. Use URL-safe (and usually unpadded) when the value goes in a URL, a query parameter or a JWT segment, because + and / have meaning in URLs.

Was Base64 ever meant to be encryption?

No, and it should never be used as one. Base64 is reversible with a single standard library call. If you need confidentiality, use real encryption or a hashing scheme — Base64 alone protects nothing.

What is 'Decode Basic auth' for?

An HTTP Basic header is Basic followed by the Base64 of user:password. That button decodes the value and splits the pair for you. It is a diagnostic convenience — never paste production credentials into any web page.

Why is the output longer than the input?

Base64 encodes 3 bytes as 4 characters, so output is roughly 33% larger, plus padding. That overhead is why Base64 is not used for large binary payloads when a binary-safe transport is available.
