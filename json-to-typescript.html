Frequently asked questions

Does my JSON get uploaded?

No. Type inference and code generation run in JavaScript in this tab. Nothing is sent anywhere — safe for API responses containing tokens, emails or customer records.

How are optional fields detected?

Only within arrays: if one object in an array has a key and another does not, that key is marked optional with ?. Across separate documents, run each one and merge the interfaces — a single payload cannot tell you what is optional in the schema.

Are nested objects inlined or named?

Named. Each nested object becomes its own interface, which is what you want for reusability, and matches how most teams write API types by hand. Arrays of objects reuse the singular name where the key is plural (orders → Order).

What about null and mixed types?

null produces a union such as string | null. Fields that are null in every sample become unknown rather than a wrong guess. Mixed arrays produce a union of the element types.

Can I generate type aliases instead of interfaces?

Yes — switch the selector to type. Everything else in the output is identical, including nested types.

Is there a size limit?

The free tier handles payloads up to roughly 2 MB. APILens Pro raises it to 20 MB and adds large-file mode.
